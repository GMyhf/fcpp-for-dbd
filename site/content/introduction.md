# C++基础能力手册

作者：臧炫懿

本书从零开始介绍 C 与 C++：先用 C 打好过程式编程与内存模型的底子，再过渡到
C++ 的资源管理、面向对象与泛型编程，最后覆盖 STL、区间视图和多线程。全书假定
读者此前**没有任何编程基础**，示例代码可直接编译运行。

## 怎么读

- 左侧目录按章节展开，顶栏可切换主题（浅色 / 深色）与全文搜索。
- 代码块右上角可一键复制；行内代码与关键字沿用书稿中的标注。
- 定理、定义、例题和注记保留了书稿中的分色样式，可通过交叉引用互相跳转。
